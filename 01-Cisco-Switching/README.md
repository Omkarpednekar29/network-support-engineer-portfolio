
# Cisco Switching

## Introduction
This project contains practical Cisco switching
concepts, commands and configuration examples.

## Topics Covered

1. VLAN Configuration
2. Access Ports
3. Trunk Ports
4. MAC Address Table
5. Spanning Tree Protocol (STP)
6. EtherChannel
7. Port Security
8. Switch Backup
9. IOS Upgrade
10. Network Troubleshooting

## Cisco Switch Models

- Cisco Catalyst 9200 Series
- Cisco Catalyst 2960 Series
- Cisco Catalyst 9500 Series

## Important Cisco Commands

### 1. Check Switch Information
show version

### 2. Check VLAN Information
show vlan brief

### 3. Check Interface Status
show interfaces status

### 4. Check MAC Address Table
show mac address-table

### 5. Check Trunk Ports
show interfaces trunk

### 6. Check Spanning Tree
show spanning-tree

### 7. Check Running Configuration
show running-config

### 8. Check Interface Configuration
show interfaces

## Learning Objectives

- Understand Cisco switch operations.
- Learn VLAN and trunk configuration.
- Understand switching protocols.
- Troubleshoot network connectivity.
- Maintain network documentation.
